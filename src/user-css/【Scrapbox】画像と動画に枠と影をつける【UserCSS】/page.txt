【Scrapbox】画像と動画に枠と影をつける【UserCSS】
[*** 概要]
記事を作成していて、白背景の画像だとページ背景との境界が分かりづらいと感じた。
そこで、Scrapbox上に表示される画像と[Gyazo]の動画に、枠と影をつける[UserCSS]を作成した。


[*** UserCSS]
code:style.css
 .page img.image,
 .page video.gyazo.image,
 .page .gyazo.oembed > iframe {
   box-sizing: border-box;
   border: 1px solid rgb(0, 0, 0);
   box-shadow: 5px 5px 5px 0 rgba(0, 0, 0, 0.5);
 }

[** 解説]
 各セレクタでは、次の要素を対象としている。
  table:セレクタ
   セレクタ	対象
   .page img.image	imageクラスを持つ画像
   .page video.gyazo.image	video要素として表示されるGyazo Video
   .page .gyazo.oembed > iframe	iframe要素として埋め込まれるGyazo Video
 `.page img.image`では、Scrapboxにアップロードした画像やGyazo画像など、配信元や`alt`属性を問わず、ページ本文内で`image`クラスを持つ画像を対象にしている。
　`.page`や`.gyazo.oembed`では、`main`や`div`などのHTMLタグ名をあえて指定していない。
　 HTMLタグ名への依存を減らし、Scrapbox側でHTML要素が変更された場合の影響を受けにくくするため。
　 Gyazoの埋め込み動画には、動画の形状などによって`.square`や`.landscape`といったクラスが付与される場合があるが、これらもあえて指定していない。
  `.gyazo.oembed > iframe`とすることで、動画の形状クラスに依存せず対象にできる。
　`box-sizing: border-box;`を指定し、境界線を要素のサイズに含めている。
　 これにより、`border`を追加したことで画像や動画の外寸が大きくなることを防いでいる。
