【UserScript】PopupMenuに「Twitterにシェア」を追加する
[*** 概要]
[Scrapbox]で日記を書いているときに、「選択した文字列をそのままツイートできたら便利そう」と思ったので作ってみました。
[PopupMenu]に「Twitterにシェア」ボタンを追加し、選択した文字列が入力された状態で[Twitter]の投稿画面を開きます。


[*** 完成したもの]
[https://gyazo.com/a25ca77d29506deb19cda83f47564160]


[*** ソースコード]
code:script.js
 // PopupMenuに「Twitterにシェア」を追加します。
 scrapbox.PopupMenu.addButton({
   title: 'Twitterにシェア',
   onClick: (text) => {
     const urlParams = new URLSearchParams({ text });
     const shareUrl = `https://twitter.com/intent/tweet?${urlParams}`;
     window.open(shareUrl, '_blank', 'width=600,height=300');
   },
 });


[** ソースコードの簡単な説明]
`scrapbox.PopupMenu.addButton({`
 [Scrapbox]の[PopupMenu]にボタンを追加する処理
 `title`：メニュー上のボタン名
 `onClick`：ボタンをクリックしたときの処理

`new URLSearchParams({...})`
 [Twitter Intent] に渡すURLパラメーターを作成する処理
 選択した文字列をtextパラメーターに設定している
 改行・空白・記号などは、URLパラメーターとして使用できる形式へ自動的に変換される
