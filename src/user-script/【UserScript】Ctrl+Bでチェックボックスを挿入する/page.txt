【UserScript】Ctrl+Bでチェックボックスを挿入する
[*** 概要]
[Cosense]（旧[Scrapbox]）の編集画面でCtrl+Bを押したとき、
カーソル位置に未チェックを表す⬜を挿入する[UserScript]。

[https://gyazo.com/e1fc70a29674c2869a687954cf2b8d0e]

以下のページを参考に作成した。
　[/nekobatoken/Ctrl-cで独自のチェックマークを挿入するUserScript]


[*** 導入方法]
対象プロジェクトでUserScriptを有効にしたうえで、自分のユーザーページに下記の記述を追加する。
既存の記事のコードをimportして使用する方法なので、この記事のソースコードをコピーする必要はない。
code:導入記述
 [/Rutile3-Tech/【UserScript】Ctrl+Bでチェックボックスを挿入する]
  code:script.js
   import '/api/code/Rutile3-Tech/【UserScript】Ctrl+Bでチェックボックスを挿入する/script.js';

追加後は本文の編集位置をクリックしてCtrl+Bを押し、⬜が挿入されることを確認する。


[*** 動作]
本文の編集中にCtrl+Bを押すと、カーソル位置へ⬜を挿入する。

以下の場合は挿入しない。
 ShiftまたはAltを同時に押している
 キーを長押ししている
 文字列を範囲選択している

日本語入力中も使用できるように、IMEの変換状態による除外は行わない。

[** 挿入例]
「作業」の先頭にカーソルを置き、Ctrl+Bを1回押す。

code:挿入前
 作業
code:挿入後
 ⬜作業

⬜だけを挿入し、後ろに空白は追加しない。行頭以外でも、カーソル位置へ挿入する。


[*** ソースコード]
code:script.js
 const CHECKBOX_SYMBOL = '⬜';
 const SELECTION_SELECTOR = '.selections .selection';

 /**
  * チェック記号を挿入するショートカットが押されたか判定する。
  * 日本語入力中も挿入できるように、IMEの変換状態は判定しない。
  *
  * @param {KeyboardEvent} e キーボードイベント
  * @returns {boolean} ショートカットの入力条件を満たす場合はtrue
  */
 function isInsertCheckboxShortcut(e) {
   return (
     e.code === 'KeyB' && e.ctrlKey && // 「Ctrl+B」を押している
     !e.shiftKey && !e.altKey &&       // ShiftかAltを押していない
     !e.repeat                         // キーリピート中ではない
   );
 }

 /**
  * キーボードイベントと選択状態から、チェック記号を挿入すべきか判定する。
  *
  * @param {KeyboardEvent} e キーボードイベント
  * @returns {boolean} チェック記号を挿入する場合はtrue
  */
 function shouldInsertCheckbox(e) {
   if (!isInsertCheckboxShortcut(e)) {
     return false;
   }

   // 文字列の範囲選択中は挿入しない。
   // Scrapboxでは、選択範囲が独自のDOM要素によって表現される。
   return document.querySelector(SELECTION_SELECTOR) === null;
 }

 /**
  * Ctrl+Bが押されたとき、Scrapboxのカーソル位置に未チェック記号を挿入する。
  * 文字列の範囲選択中およびキーリピート時は挿入しない。
  *
  * @param {KeyboardEvent} e キーボードイベント
  * @returns {void}
  */
 function handleKeydown(e) {
   if (shouldInsertCheckbox(e)) {
     document.execCommand('insertText', null, CHECKBOX_SYMBOL);
   }
 }

 document.addEventListener('keydown', handleKeydown);



[*** 仕組み]
`document`のkeydownイベントを受け取り、以下の順に判定する。
 `isInsertCheckboxShortcut()`
  `code`が`KeyB`、Ctrlが押されている、ShiftとAltが押されていない、キーリピートではないことを確認する。
 `shouldInsertCheckbox()`
  選択範囲を表す`.selections .selection`が存在しないことを確認する。
 条件を満たした場合
  `document.execCommand('insertText', null, CHECKBOX_SYMBOL)`で⬜を挿入する。

キー判定には、物理的なキー位置を表す`KeyboardEvent.code`を使用している。
`KeyboardEvent.key`を併用する判定は採用していないため、異なるキーボード配列やマクロデバイスでの入力は、この判定条件に依存する。


[*** 注意点]
 Ctrl+Bに割り当てられている既存の操作と競合する可能性がある。
  `preventDefault()`は呼び出していないため、挿入時も既定の操作を抑止しない。
 本文編集中に使用することを想定しているが、フォーカスが本文の入力欄にあるかを判定する処理はない。
  検索欄など、本文以外へフォーカスがある状態での挙動は未確認。
 スクリプトの再評価時に、以前のkeydownイベントリスナーを解除する処理はない。
  再評価による重複登録を防ぐ仕組みは未対応。
 選択範囲の判定にCosense内部のDOM構造を利用しているため、Cosense側の仕様変更によって動作しなくなる可能性がある。
 document.execCommand()は非推奨のAPIだが、ブラウザのUndo履歴を維持したまま文字を挿入できる利点があるため使用している。
 　将来的に動作しなくなった場合は、Cosenseの#text-inputに対してsetRangeText()を使用する方法などへの変更を検討する。
  `setRangeText()`でUndo履歴とCosenseの入力状態を維持できるかは未検証のため、現時点では置き換えていない。
