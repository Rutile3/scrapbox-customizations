# 仕様変更

## 2026-08-25

### toggle-checkbox

- カーソル行の取得失敗をエラーとして識別できるよう、例外の出力を `console.log` から `console.error` に変更
- ログの分類だけを変更し、例外発生後に処理を終了する既存の挙動は維持
- チェック記号の二次元配列を平坦化する処理を `reduce` と `concat` の組み合わせから `Array.prototype.flat()` に変更
- 配列を一段階だけ平坦化する既存の挙動は維持
- 行頭のチェック記号を判定する前処理を `trim()` から `trimStart()` に変更し、目的を先頭空白の除去に限定
- 末尾空白は判定に使用しないため、既存のチェック記号の判定結果は維持
- チェック状態のデータ構造、keydown イベント送信クラス、および補助関数へ JSDoc を追加
- 型、引数、戻り値、およびカーソル行が見つからない場合の例外を文書化し、実行時の挙動は変更しない
- チェック状態の循環、記号一覧、行テキスト、および次に書き込む記号の役割が分かるように変数名を整理
- 名前だけを変更し、チェック状態を判定して切り替える既存の処理順序は維持
- 右矢印キーと Backspace キーのキーコードを `KEY_CODE` 定数へ集約
- 疑似 keydown イベントへ渡す数値と送信方法は維持
- 次のチェック記号を求める処理を `getNextCheckboxSymbol` 関数としてイベント処理から分離
- チェック状態の切替順序と、記号を特定できない場合に現在の文字列を返す挙動は維持

### 開発環境

- VS Code 標準の JavaScript フォーマッターを使用する共有設定を `.vscode/settings.json` に追加
- 保存時整形、2 スペースのインデント、LF、末尾改行、および行末空白の削除を設定
- 個人用の `*.code-workspace` は Git の管理対象外とし、共有設定との役割を分離
